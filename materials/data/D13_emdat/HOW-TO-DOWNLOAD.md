# EM-DAT – download it yourself

EM-DAT (CRED/UCLouvain) lists more than 27,000 disasters worldwide since 1900. Its terms require registration and do not allow redistribution, so the data is not part of this pack.

1. Go to https://public.emdat.be and create a free account (academic use).
2. Accept the terms of use.
3. Use *Access Data*, filter (e.g. disaster type: heat wave, flood, drought) and download the Excel file.
4. Do not share the file further.
